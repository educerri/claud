# Caminhando pelo Circuito

Jogo educativo em JavaScript puro: você é uma carga percorrendo um circuito de 3 malhas, 8 resistores e 2 fontes (100 V e 70 V). A visão é em primeira pessoa, andando por cima dos fios; em cada quina você escolhe o caminho pelas setas no centro da tela e aprende Lei de Ohm e Leis de Kirchhoff.

Para jogar, abra `index.html` no navegador.
